# Overview

A networked terminal application that allows two players to compete in real time from different computers through a clean command-link interface. Unlike graphical interfaces, this game runs entirely on the terminal while providing a clean, easy-to-interact and polished experience with animations, keyboard navigation, coloured UI elements and live game synchronization between players.


- The project consists of a client-server architecture, where a server performs room creations, move validations, player connections/disconnections and game state, while the client manages the interface for players while communicating with the server.
